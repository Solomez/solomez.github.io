A mining calculator: a six-column table that also works on a phone

  • The only designer
  • Private client
  • 2025–2026
Context
Miningx100, an online store for mining hardware
Role
the only designer on the project, for a private client; the calculator is mine, UX and UI
When
2025–2026
Status
launched
Site
miningx100.ru/calculator
AI
used for the interface copy

The client asked for the calculator after we looked at competitors. A buyer enters the electricity price and the pool fee and sees the payback period, income, costs and profit for each miner. On a wide screen this is a table with six columns; on a phone I turned it into a list of cards, one per miner.

In the first phone version all the settings came before the list, so a buyer saw no miners on the first screen. In the final version three filters, the algorithm, the manufacturer and the cooling, sit under a “Filter” button. The two number fields, the electricity price and the pool fee, stay on screen; the coin rate field is gone, and the coin rates take one line instead of two. The first miner is now in view.

I designed the calculator for four screen sizes, with its states, such as an empty result and a table header that stays in view on scroll. The site is in Russian; the screens here are translated.

Next time I would plan more time for the design work, build the UI kit in more depth, and set out all the tasks and their deadlines more clearly before starting.
